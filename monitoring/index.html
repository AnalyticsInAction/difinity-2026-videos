Monitoring AI agents

Checking that what agents do still matches what we agreed · 4-minute narrated explainer · as of November 2026

Interactive version (animation in the browser) Download MP4 (6 MB)

Tenant, capacity and workspace admins can all grant access, so permissions drift. Monitoring checks that what is actually happening still matches what was intended.

What it covers

  • Where are agents operating? Scanner metadata: the tenant inventory of workspaces, items, data sources and sensitivity labels.
  • What can they access? Identity and permissions, including the reverse question: what can this one identity reach?
  • What are they doing? Activity events. The API keeps about four weeks of history, so land it daily in your own storage.
  • Bring the three together in a lakehouse, model it, and report on it.
  • Someone owns a regular review and acts on the gaps. Over-privileging is the most common finding, so start there.

Sources (checked November 2026): Microsoft Learn: Fabric metadata scanning; Fabric admin REST APIs (item access details, user access entities); Power BI activity log guidance. Drift examples, the 90-day rule, review cadence and report names are illustrative.
